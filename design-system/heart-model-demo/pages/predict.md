# Fictional example tool

- Lead with the independent project identity, a plain-language title, and a visible educational-use boundary.
- Show the fictional input form and the default model output together. Never imply that the score is a personal probability.
- Give visitors two fictional starting examples and a custom-fictional-values path. Do not describe presets as typical health states. Choose presets on clearly opposite sides of the cutoff (one strong negative, one strong positive) so the label meaning is immediately legible.
- Group the 11 selected fields, keep visible labels and short field help, and constrain values to observed dataset limits rather than clinical ranges.
- The output updates on preset change or form submission. Label the threshold-based class as an original source-data label.
- Use native Streamlit controls, keyboard focus, reduced-motion support, Inter type, the white/blue token palette, and responsive columns. Avoid icon tiles, red/green risk colors, progress bars, and decorative effects.
- Do not use the Vercel wordmark or logos; this project is independent and must not imply endorsement.
